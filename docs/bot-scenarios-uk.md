# Сценарії Telegram-бота: що приходить, кому, як перевірити

Бот: https://t.me/gravity_test_promo_bot · запуск: `npm run bot` · технічний опис: [17](17-telegram-bot.md), [BOT.md](../BOT.md).
Неофіційний демо-стенд, дані синтетичні. Бот нічого не надсилає клієнтам: лише чернетки й посилання для людини.
Ролі: Продажі, Інженер, Закупівлі, PM (керівник проєктів), Сервіс, HR. Адмін і PM отримують і можуть натискати все.

## Повідомлення (бот перевіряє Odoo кожні 30 с)

| # | Подія | Кому | Кнопки | Як відтворити |
|---|---|---|---|---|
| 1 | 🆕 Новий лід з AI-розбором (пріоритет, послуги, бюджет, чого бракує, наступний крок) | Продажі | Взяти в роботу · Чернетка відповіді · 📅 Консультація · Створити пропозицію | Заявка на https://test6017.odoo.com/zayavka або `npm run eval` |
| 2 | 📅 Клієнт записався на консультацію (час — Київ) | Продажі | Відкрити в Odoo | Запис на https://test6017.odoo.com/appointment (в інкогніто) |
| 3 | 💬 Передоплату отримано: запустити закупівлі | PM | Відкрити в Odoo | `npm run e2e:contract` |
| 4 | 📐 AI-чернетка специфікації готова | Інженер | Погодити специфікацію (→ чернетки закупівель) | `npm run e2e:spec` |

| 6 | ✅/🔵/🟣 Зміна етапу проєкту | PM | Картка проєкту | Змінити етап у `/project_ID` або в Odoo |
| 7 | 👉 Ваша черга: наступний етап (лише коли закрито етап перед ним) | Власник етапу | Взяти в роботу · Картка проєкту | Етап → «Готово» у `/project_ID` |

| 13 | 👤 Новий кандидат з AI-профілем (AI не відхиляє) | HR | Відкрити в Odoo | `npm run e2e:applicants` |
| 14 | ☀️ Ранковий дайджест (ліди, прострочення, сервіс) | Усі з доступом | — | Автоматично щодня або `/digest` |

Перший запуск бота «тихий»: запам’ятовує наявні записи й не засипає чат історією.

## Команди

| Команда | Що робить |
|---|---|
| `/help` | Список команд і типів повідомлень |
| `/flow` | Як працює процес: етапи, відділи, хто кому передає роботу |
| `/leads`, `/lead_ID` | Ліди без пропозиції (🆕 нові / 🟢 в роботі); картка ліда з кнопками |
| `/projects`, `/project_ID` | Усі об’єкти з прогресом; картка проєкту з кнопками етапу і 🧪 Чекліст |
| `/stats` | Звіти: ліди, кампанії, прострочення, сервіс (зокрема % SLA вчасно), воронка |
| `/digest`, `/overdue` | Дайджест зараз; прострочені задачі |
| `/whoami`, `/request` | Свій chat ID; запит доступу в адміна |
| `/users` | Адмін: ролі, закрити / відкрити доступ |

## Права на кнопки
Кожна кнопка — для своєї ролі; інакше відповідь «Ця дія для ролі …» і в Odoo нічого не змінюється.
Кожна дія лишає нотатку в Odoo (хто натиснув через Telegram) і дає посилання на запис.

## Перевірити все одразу
`npm run regression` — eval і 13 наскрізних сценаріїв через API Odoo; при запущеному боті приходять повідомлення 1, 3–11, 13.
Останній прогін 05.11.2026: 14/14. Не покрито тестом: №2 (перевірено вручну), №12 (SLA рахує Odoo, змінити дедлайн через API не можна — перевіряємо на реальному тікеті).
